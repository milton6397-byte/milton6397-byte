# 🤖 NEXA IA

**Assistente de Inteligência Artificial local** desenvolvida em Python.

> Projeto em desenvolvimento — focado em aprendizado prático de programação, Inteligência Artificial e integração entre software e hardware.

---

## 📌 Sobre o Projeto

A **NEXA IA** é uma assistente de inteligência artificial que roda localmente, sem depender de serviços na nuvem. O objetivo é criar uma solução completa e funcional, unindo:

- Interface gráfica
- Banco de dados
- Modelo de linguagem local (LLM)
- Síntese de voz (TTS)
- Reconhecimento de fala (STT)
- Automações

Este projeto serve como laboratório prático para o estudo de programação, Linux, Inteligência Artificial e integração com hardware.

---

## 🛠️ Tecnologias Utilizadas

| Área                    | Tecnologias                          |
|-------------------------|--------------------------------------|
| Linguagem               | Python                               |
| Interface Gráfica       | Kivy                                 |
| Banco de Dados          | SQLite                               |
| Modelo de Linguagem     | Qwen (LLM local)                     |
| Voz                     | TTS (Text-to-Speech) + STT (Speech-to-Text) |
| Sistema                 | Linux                                |
| Hardware (experimentos) | Raspberry Pi, ESP32, Arduino         |
